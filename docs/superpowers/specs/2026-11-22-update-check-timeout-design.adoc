= OpenAI 仪表盘 1.18.1 更新检查超时设计
:toc: left
:sectnums:

== 目标

更新检查最多显示“检查中…”30 秒。超过 30 秒后恢复按钮并提示超时；Sparkle 旧会话仍在结束时不得启动第二个请求。

== 状态与超时

沿用现有 `UpdateStatus`，新增带世代号的 30 秒 `.common` RunLoop 看门狗。看门狗只处理当前且仍为 `.checking` 的检查，改为 `.failed` 并设置“检查更新超时，请稍后重试。”。后台检查保持静默，手动检查显示现有 4 秒吐司。

Sparkle 没有取消信息探测的公开 API，因此看门狗不强行取消底层请求。若 `sessionInProgress` 仍为真，重复点击只提示“上一次检查仍在结束，请稍后重试。”。迟到的有效结果仍可更新为 `.current` 或 `.available`。

== 范围

* 不增加应用层自动重试次数。
* 保持启动一次、之后每 8 小时自动检查。
* 保持现有错误链解析和设置页版本行布局。
* 新增纯 Swift 超时策略测试；版本升至 1.18.1，重新构建、推送并发布 universal2 DMG。

== 验证

覆盖当前世代超时、旧世代无效、后台静默、重复会话提示和迟到结果；运行现有更新状态/错误测试、双架构构建、签名与 DMG 校验。完整独立 Intel 与 Apple Silicon 更新流程无环境时标为未验收。
